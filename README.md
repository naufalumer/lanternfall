**Lanternfall** is a complete, original 2D survival game for the browser. You are the Keeper of the last lantern in a drowned forest at night, and the Hollow is pouring in. Move with WASD or the arrow keys, dash with Space, and let your lantern fight on its own: its flare, orbiting embers, dawn beam, sparks and thorn ward cut the dark down while you gather ember shards, level up, and choose blessings that shape the run. Wardens arrive every minute. At 5:00 the Hollow King comes — banish him and the dawn returns.

- Five weapons with five levels each, six passive blessings, six enemy kinds plus elites, wardens and a final boss
- A real win and a real loss: victory and game-over screens with run stats, best records kept in localStorage
- Feel: particles, screen shake, hit-stop, damage numbers, synthesized WebAudio effects and a night pad — zero audio, image or font assets, zero network requests
- Vanilla JavaScript on canvas, no engine, no build step: open `game/index.html` from any static server and play

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. `P` pauses, `M` mutes, `R` restarts, `1`/`2`/`3` pick a blessing at level-up.
